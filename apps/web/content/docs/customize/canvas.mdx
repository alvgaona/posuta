You can throw away the template's header, footer and sections and write the poster's layout
yourself, in plain HTML and CSS. As long as it sits on `<Canvas>`, you keep the print page size,
the PDF export, the overflow check, the `?print` preview and the link-preview tags.

`<Canvas>` draws nothing you can see: it renders the page's `<html>` and `<head>` and one
`div.posuta-canvas` around your content, the printed sheet. Its props, such as `print` and
`theme`, and its markup are on the [Canvas component page](/docs/components/canvas).

## A layout of your own

A layout is an Astro file in `src/layouts/`. It receives the page's frontmatter and puts the
page's content where `<slot />` is.

```astro title="src/layouts/Mine.astro"
---
import Canvas from "posuta/Canvas.astro";
import "../styles/poster.css";        // your CSS
const { frontmatter: fm } = Astro.props;
---
<Canvas title={fm.title} print={fm.print} theme={fm.theme} class="sheet"> <!-- [!code highlight] -->
  <header class="banner" data-name="the banner">
    <h1>{fm.title}</h1>
    <p>{fm.authors}</p>
  </header>
  <main class="grid"><slot /></main>
</Canvas>
```

Point the poster at it in the frontmatter. Any field you add to the frontmatter, such as
`authors` here, is yours to read in the layout.

```mdx title="src/pages/index.mdx"
---
layout: ../layouts/Mine.astro
title: A Poster Built From the Tools Only
authors: A. Author · B. Author · Some Lab
print: A2 landscape
---
```

`data-name="the banner"` gives the header a name for the
[overflow check](/docs/print/pdf#the-overflow-check), since it doesn't start with a heading.

To add tags to `<head>`, such as a favicon, give them `slot="head"`; see
[Canvas](/docs/components/canvas#tags-in-the-head).

## Pages without Canvas

`posuta pdf` only exports pages built on `<Canvas>`. Without it, the page has no print size and
no sheet to measure, and the export stops with `wrap it in <Canvas>`. The `?print` preview also
needs `<Canvas>`.

## A whole example

[`test/fixtures/custom`](https://github.com/alvgaona/posuta/tree/main/packages/posuta/test/fixtures/custom)
in the posuta repository is a poster built without the template. posuta's tests build it and
export it to PDF, so it stays working. It shows:

- **Its own layout** (`src/layouts/Banner.astro`): a full-width banner and a three-column CSS
  grid on `<Canvas>`, styled by a plain stylesheet, `src/styles/poster.css`. No template theme,
  no `Row` or `Col`: the sections are plain `<section>` elements laid out by the grid.
- **A hand-drawn SVG** (`src/components/Sketch.astro`): two states and an arrow, with maths labels
  from `texSvg()` in `posuta/tex`.
- **A chart** with maths in its axis labels, from an inline `plot` function.
- **Citations** in APA style (`posuta({ citationStyle: "apa" })`) and a `<References />` list.
- **Your own rehype plugin**, passed through `posuta({ rehypePlugins })`
  ([components and plugins](/docs/customize/plugins)).
- **Tailwind** (`src/pages/tailwind.mdx`): a small theme in the `posuta.theme` layer, Tailwind
  utilities on `Grid`, `Figure` parts and `References` parts, a video with its print frame, and a
  QR code that shows only in print.
- **The overflow check** (`src/pages/overflow.mdx`): a page that is too tall on purpose.
