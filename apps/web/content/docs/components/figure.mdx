`<Figure>` places a picture with a caption, whether an SVG from matplotlib or a diagram tool, a
photo, or a video that prints as a still frame.

<ComponentPreview name="figure-svg" />

## Usage

Import the file at the top of the MDX page, then pass it as `src`.

```mdx title="src/pages/index.mdx"
import poles from "../../figures/poles.svg";

<Figure src={poles} alt="The s-plane, with the poles of two systems." caption="Poles on a circle of radius ωn." />
```

The import path is relative to the page. `alt` is required. The build stops without it.

## Examples

### SVG

An imported SVG is written into the page rather than linked. Its text uses the poster's fonts,
it prints as vectors, and anything drawn in `currentColor` follows the page between light and
dark. It keeps its own attributes and classes, and `$…$` in its text is typeset with KaTeX. This
is how matplotlib figures and diagrams from Graphviz, Mermaid or draw.io reach the poster.

<ComponentPreview name="figure-diagram" />

### Image

An imported image (`.png`, `.jpg`, …), or a path to a file in `public/` such as `"/photo.jpg"`,
becomes a plain `<img>`. posuta does not resize or compress it, so use a file with enough pixels
for the printed size.

<ComponentPreview name="figure-image" />

### Video

A video (`.mp4`, `.webm`, `.mov`, `.m4v` or `.ogv`) needs `poster`, the still frame that
prints. The build stops without it. On screen the video has controls, plays inline on phones and
loads only its metadata until the reader presses play. In print, and in the PDF, the `poster`
image takes its place.

To add `muted`, `loop` or `autoplay`, use the parts and put them on `Figure.Media`. On the
one-line `<Figure>`, extra attributes go on the outer `<figure>`, not on the video.

<ComponentPreview name="figure-video" />

A printed poster can't play the video. To point readers elsewhere, add a line that shows only in
print, such as `<p data-print="only">Scan the QR code to watch it.</p>`.

### Parts

`<Figure>` is built from three parts, `Figure.Root`, `Figure.Media` and `Figure.Caption`. Use
them directly to put the caption above, wrap the picture in a link, or add a credit line. Put
them in any order, with any markup between them.

<ComponentPreview name="figure-parts" />

`Figure.Root` and `Figure.Caption` take `as` to render another element, such as
`<Figure.Root as="div">`.

### Markup and class hooks

```html
<figure class="posuta-figure">
  <!-- an SVG -->
  <svg class="posuta-media" role="img" aria-label="…">…</svg>
  <!-- or an image -->
  <img class="posuta-media" src="…" alt="…" />
  <!-- or a video, and its print frame -->
  <video class="posuta-media" data-print="hide" controls playsinline preload="metadata" …></video>
  <img class="posuta-media" data-print="only" src="…" alt="…" />
  <figcaption class="posuta-caption">…</figcaption>
</figure>
```

posuta's CSS only makes `.posuta-media` fill the width of its container, keeping its proportions.
Margins, the caption's size and colour, and any border are yours. See
[CSS, Tailwind and hooks](/docs/customize/css).
