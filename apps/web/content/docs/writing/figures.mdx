A figure reaches the poster as a file: an SVG from matplotlib or a diagram tool, a photo, or a
video. You place it with [`<Figure>`](/docs/components/figure), which writes an SVG into the page
so it uses the poster's fonts, prints as vectors and follows dark mode. This page covers making
the files and getting them onto the page; the component page lists every prop and variant.

## Where the files go

Keep figures in the project's `figures/` folder and photos and videos in `src/media/`, as the
template does. An MDX page imports a file by its path relative to the page, so from
`src/pages/index.mdx` the `figures/` folder is `../../figures/`:

```mdx title="src/pages/index.mdx"
import loop from "../../figures/loop.svg";
import clip from "../media/oscillator.mp4";
import still from "../media/oscillator.jpg";
```

Then pass the import to `<Figure src={loop} alt="…" />`. A file in `public/` needs no import:
give its path, such as `src="/photo.jpg"`.

## Figures from matplotlib

posuta ships a matplotlib style that matches the default theme: its fonts and colours, no
background, no top or right axis lines, and text kept as text so it uses the poster's fonts.
Use it and save as SVG:

```python title="figures/poles.py"
from pathlib import Path

import matplotlib.pyplot as plt

here = Path(__file__).parent
plt.style.use(here.parent / "node_modules/@posuta/posuta/posuta.mplstyle")  # [!code highlight]

fig, ax = plt.subplots(figsize=(4.6, 3.0))
# … plot as usual …

out = here / "poles.svg"
fig.savefig(out)
# Text in currentColor, so the figure follows the page in dark mode.
out.write_text(out.read_text().replace("#282a30", "currentColor"))
```

The last line swaps the style's text colour, `#282a30`, for `currentColor`, so the labels turn
light in dark mode. Run the script whenever the data change, then place the SVG with `<Figure>`.
The template's `figures/poles.py` runs with:

```sh title="Terminal"
uv run --with matplotlib figures/poles.py
```

or `python figures/poles.py` with matplotlib installed.

<Callout title="Keep the text as text">
The style sets `svg.fonttype: none`. Without it, matplotlib turns each letter into a path: the
figure no longer uses the poster's fonts and its text can't be searched or selected.
</Callout>

## SVG from other tools

Any tool that exports SVG works the same way: Graphviz, Mermaid, D2, TikZ, draw.io or
Excalidraw. Two settings make the result fit the poster:

- **Text as text**, not outlines, so it uses the poster's fonts and can be searched.
- **`currentColor`** for lines and text, so the drawing follows the page between light and dark.

[Diagrams](/docs/writing/diagrams) walks through one from Graphviz and lists other tools.

## Photos and video

posuta does not resize or compress images, so export photos with enough pixels for the printed
size. A video needs a still frame for print, the `poster`; export one from the video at a moment
that tells the story on its own. See [Figure](/docs/components/figure#video) for placing both.

## Plain Markdown images

Markdown's own image syntax works too, without a caption:

```mdx title="src/pages/index.mdx"
![A test flight over the lab's netted area](../images/flight.jpg)
```
