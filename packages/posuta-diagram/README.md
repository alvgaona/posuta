# posuta-diagram

Block diagrams for [posuta](https://github.com/alvgaona/posuta) posters: boxes on a coarse grid,
arrows that route themselves, `$maths$` labels, drawn to SVG at build time. Optional; posuta works
without it.

```sh
pnpm add posuta-diagram
```

See posuta's README, "Diagrams", for the spec and the API (`layout`, `draw`, `route`).
